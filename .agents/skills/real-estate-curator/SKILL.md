# Real Estate Curator

공식 자료를 원문에 가깝게 확인하고, 수치와 정책의 적용 범위를 보존한 장문 해설 포스트를 작성한다. 사용자가 요청한 샘플은 요약문이 아니라 원자료의 구조와 맥락을 독자가 이해할 수 있도록 재구성한 글이다.

독립 포스트는 제목과 YAML frontmatter를 제외한 Markdown 본문을 **공백 포함 2,500~4,000자**로 작성한다. 이 범위는 기본 목표이며, 글자 수를 맞추려고 내용을 반복하거나 주요 수치·정책 조건·예외를 생략하지 않는다. 하나의 핵심 질문으로 4,000자를 넘는다면 사용자가 장문을 요청했거나 원자료의 적용 범위를 정확히 보존하는 데 꼭 필요한 경우로 제한하고, 서로 다른 쟁점이 섞였다면 개별 포스트로 나눈다.

## Workflow

1. `src/data/taxonomy.ts`의 부동산 허브와 콘텐츠 스키마를 확인한다.
2. 국토교통부 정책·보도자료, 한국부동산원 주택가격동향·거래통계, 한국은행 금융시장·금융안정보고서를 우선 조사한다.
3. 발표일, 조사 기준일, 기준시점, 표본과 지역 범위를 본문에 명시한다.
4. 원자료의 주요 수치·정책 조건·예외·시행 시기를 축약하지 않고 보존한다. 길이를 줄이기보다 소제목과 표로 읽기 쉽게 재배열한다.
5. `무슨 자료인가 → 원문이 말하는 내용 → 시장·거주자에게 의미 → 확인할 한계` 순서로 작성한다.
6. 정책은 확정된 제도와 발표된 계획, 기관의 전망을 서로 다른 표현으로 구분한다.
7. `src/content/posts/YYYY-MM-DD-<slug>.md`에 `editorial`의 출처와 검수 상태를 기록한다.
8. 개인의 매수·매도, 대출 실행, 세금 신고를 지시하지 않고 법률·세무 판단은 전문가 확인이 필요하다고 표시한다.

## Topic rules

- 시장 동향: 매매·전세·월세를 분리하고 전국·수도권·지역 수치를 섞지 않는다.
- 정책·제도: 대상, 공급·금융 규모, 시행 시기, 담당 기관과 후속 절차를 모두 적는다.
- 청약·분양: 공고일, 공급 대상, 자격 조건, 일정은 원문 링크와 함께 확인한다.
- 전세·임대: 보증금·월세·대출·보증을 혼용하지 않고 계약 당사자별 위험을 구분한다.
- 리츠·상업용: 부동산 가격과 임대수익률, 공실률, 금리 민감도를 분리한다.
