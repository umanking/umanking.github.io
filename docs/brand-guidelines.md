# BRIEFLO · 브리플로

공개 브랜드: BRIEFLO. 한글: 브리플로. 워드마크: brieflo.
슬로건: 필요한 정보만, 흐름까지 명확하게. / Less noise. More clarity.
금융·생활·정책·부동산·기술을 수치·일정·조건·공식 근거로 설명하는 정보 매거진.
차분하고 명료한 편집 어조. 과장, 결과 보장, 근거 없는 긴급성을 사용하지 않는다.

## 시각 기준

아이보리 에디토리얼: Primary #262b22, Secondary #faf9f5, Accent #4c6037.
글꼴은 기존 Pretendard를 유지한다. 실제 화면 토큰은 src/styles/tokens.css가 관리한다.
브랜드 교환용 토큰은 assets/design-tokens.json 및 assets/design-tokens.css에 동일하게 보존한다.
파비콘은 public/brieflo-icon.svg의 B 심볼. 작은 크기에서 장식·문구를 추가하지 않는다.
앞으로 생성하는 브랜드 이미지에는 BRIEFLO 또는 brieflo를 사용하며 Naver 계정 이름은 바꾸지 않는다.

## 호환성

저장소명, codenexus 채널 ID, 기존 게시 URL, 계정·분석 ID는 변경하지 않는다.
과거 기사·발행 이력·기존 이미지 안의 표기는 역사적 자료로 보존한다.
